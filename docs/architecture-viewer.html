1. Application startup

What happens from running the JAR to the browser opening.

flowchart TD
    A["You run the JAR file"] --> B["main in DailyStatusReportWebApplication"]
    B --> C["SpringApplication.run"]
    C --> D["Read application.properties"]
    D --> E["Scan package com.statusreport"]
    E --> F["Create beans and inject dependencies"]
    F --> G["Start Tomcat on port 8081"]
    G --> H["ApplicationStartedEvent"]
    H --> I["StartupLogger logs started"]
    I --> J["ApplicationReadyEvent"]
    J --> K["StartupLogger logs ready"]
    J --> L["BrowserLauncher opens localhost"]
    L --> M["You see the form"]
    style A fill:#dbeafe,stroke:#1e40af
    style M fill:#dcfce7,stroke:#15803d

2. Generate report - full sequence

POST /generate: validate, write Excel, open Outlook draft.

sequenceDiagram
    autonumber
    actor U as You
    participant B as Browser
    participant C as ReportController
    participant S as ReportService
    participant P as TaskParser
    participant E as ExcelWriter
    participant O as OutlookService
    participant PS as PowerShell
    participant X as Outlook
    U->>B: Click Generate
    B->>C: POST /generate
    C->>S: generate tasks
    Note over S,P: Step 1 validate
    S->>P: parse
    P-->>S: clean tasks
    Note over S,E: Step 2 Excel
    S->>E: write xlsx
    E-->>S: file saved
    Note over S,X: Step 3 Outlook
    S->>O: openDraft
    O->>PS: run script
    PS->>X: COM Display draft
    X-->>U: Draft opens
    S-->>C: ReportResult
    C-->>B: success page
